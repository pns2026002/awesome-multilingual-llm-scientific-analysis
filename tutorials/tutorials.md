# Tutorials and Learning Resources

Curated authoritative tutorials, courses, documentation, and benchmark resources for **Evaluating Multilingual Reliability of LLMs in Scientific Literature Analysis**.

---

## 1. Hugging Face NLP Course

| Field | Details |
|-------|---------|
| **Type** | Interactive Online Course |
| **Provider** | Hugging Face |
| **Cost** | Free |
| **Link** | [https://huggingface.co/learn/nlp-course](https://huggingface.co/learn/nlp-course) |

**Description**: Comprehensive hands-on course covering Transformer architectures, fine-tuning multilingual models, building NLP pipelines, and deploying models. Chapters specifically cover multilingual tokenization, cross-lingual transfer, and working with mBERT/XLM-R.

**Relevance**: Essential foundation for implementing and evaluating multilingual LLMs on scientific tasks; directly teaches the tools (Transformers, Datasets, Evaluate) used in this research area.

## 4. XTREME Multilingual Benchmark

| Field | Details |
|-------|---------|
| **Type** | Research Benchmark + Starter Kit |
| **Provider** | Google Research |
| **Cost** | Free |
| **Link** | [https://sites.research.google/xtreme](https://sites.research.google/xtreme) |
| **GitHub** | [https://github.com/google-research/xtreme](https://github.com/google-research/xtreme) |

**Description**: XTREME (Cross-lingual TRansfer Evaluation of Multilingual Encoders) is the standard benchmark for evaluating multilingual model performance across 40 languages and 9 tasks including NLI, NER, QA, and sentence retrieval. Includes leaderboards, evaluation scripts, and starter training code.

**Relevance**: Directly applicable as an evaluation framework for this research topic; provides standardized evaluation scripts and leaderboard comparisons for multilingual LLMs on tasks analogous to scientific literature analysis.

| Field | Details |
|-------|---------|
| **Type** | API Documentation + Tutorial |
| **Provider** | Allen Institute for AI |
| **Cost** | Free (with API key) |
| **Link** | [https://api.semanticscholar.org/](https://api.semanticscholar.org/) |

**Description**: Semantic Scholar API provides programmatic access to metadata, abstracts, citations, and full-text links for 200M+ scientific papers. Includes multilingual paper records and supports bulk data access for research.

**Relevance**: Essential resource for building multilingual scientific paper corpora programmatically; enables researchers to collect, filter, and analyze papers across languages for LLM evaluation pipelines.
